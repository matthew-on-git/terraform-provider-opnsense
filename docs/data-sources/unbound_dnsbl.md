# opnsense_unbound_dnsbl (Data Source)

Reads the Unbound DNSBL compatibility owner. The only accepted identity is `unbound-dnsbl`. This data source never writes, deletes, or reconfigures the service.

Released core 26.7.8 and 26.7.9 store blocklists as `dnsbl.blocklist` items. The lookup uses the existing search reader and `get_dnsbl` for the sole item, plus the settings GET for `general.safesearch`. It does not call `get_dnsbl` without a UUID. Zero items are not found. More than one item fails closed. The public allowlist is the resource refresh contract. `source_nets`, `cache_ttl`, and `description` are not lookup state. The node has no password or write-only secret. A missing or blank enabled flag fails closed. Optional booleans stay null when blank. An empty address stays empty.

## Example Usage

```terraform
# Read the Unbound DNSBL compatibility owner.
# Identity is unbound-dnsbl. The lookup never writes or reconfigures.
data "opnsense_unbound_dnsbl" "example" {
  id = "unbound-dnsbl"
}

output "unbound_dnsbl_enabled" {
  value = data.opnsense_unbound_dnsbl.example.enabled
}
```

- `nxdomain` (Boolean) Return NXDOMAIN for blocked entries. A blank optional flag stays null and is not replaced with false.
- `safe_search` (Boolean) Force safe search. Read from `general.safesearch`, not from the blocklist item. A blank or omitted optional flag stays null.
- `type` (Set of String) Selected built-in blocklist feed keys. Unselected option keys are not state.
- `whitelists` (Set of String) Selected allow-domain entries. The wire field is `allowlists`.
- `wildcards` (Set of String) Selected wildcard domain entries.
