# opnsense_quagga_general (Data Source)

Reads the FRR general settings singleton. The only accepted identity is `general`. This data source calls the stable Quagga/FRR GET and never writes or reconfigures the service.

The public allowlist is the resource contract that the released general node returns: enabled, profile, CARP, syslog, SNMP, syslog level, and firewall rules. Volatile daemons and manual configuration are not lookup state. The released general node has no password or write-only secret. Missing required fields are not replaced with model defaults. A disabled flag stays false.

## Example Usage

```terraform
# Read the FRR general settings singleton.
# Identity is general. The lookup never writes or reconfigures.
data "opnsense_quagga_general" "example" {
  id = "general"
}

output "frr_profile" {
  value = data.opnsense_quagga_general.example.profile
}
```

## Schema

### Required

- `id` (String) Synthetic singleton ID. Must be `general`.

### Read-Only

- `enable_carp` (Boolean) Enable CARP failover integration. A disabled value stays false.
- `enable_snmp` (Boolean) Enable SNMP (AgentX). A disabled value stays false.
- `enable_syslog` (Boolean) Enable syslog logging. A disabled value stays false and is not replaced with the model default.
- `enabled` (Boolean) Enable the FRR routing service. A disabled service stays false and is not replaced with a default.
- `firewall_rules` (Boolean) Automatically generate firewall rules for routing protocols. A disabled value stays false and is not replaced with the model default.
- `profile` (String) Routing profile, `traditional` or `datacenter`. A missing value is not replaced with the model default.
- `syslog_level` (String) Syslog verbosity. One of `critical`, `emergencies`, `errors`, `alerts`, `warnings`, `notifications`, `informational`, or `debugging`. A missing value is not replaced with the model default.
