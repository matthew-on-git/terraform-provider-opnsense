# opnsense_quagga_ospf_general (Data Source)

Reads the OSPF general settings singleton. The only accepted identity is `ospf`. This data source calls the stable Quagga/FRR GET and never writes or reconfigures the service.

The public allowlist is the resource contract that the released OSPF node returns: enabled, router ID, cost reference, adjacency logging, default-route origination, origination metric, and CARP demote. Child arrays are not lookup state. `passive_interfaces` is absent from the released OSPF node, so it is not lookup state. The released OSPF node has no password or write-only secret. Missing required fields are not replaced with model defaults. A disabled flag stays false. A blank optional router ID, cost reference, or metric stays null. Literal cost reference 0 fails closed. Literal metric 0 is a real value.

## Example Usage

```terraform
# Read the OSPF general settings singleton.
# Identity is ospf. The lookup never writes or reconfigures.
data "opnsense_quagga_ospf_general" "example" {
  id = "ospf"
}

output "ospf_enabled" {
  value = data.opnsense_quagga_ospf_general.example.enabled
}
```

## Schema

### Required

- `id` (String) Synthetic singleton ID. Must be `ospf`.

### Read-Only

- `carp_demote` (Boolean) Demote CARP if OSPF is not converged. A disabled value stays false and is not replaced with the model default.
- `cost_reference` (Number) Reference bandwidth in Mbit, from 1 through 4294967. A blank or omitted value stays null. Literal 0 is not the resource unset sentinel and fails closed.
- `enabled` (Boolean) Enable OSPF. A disabled service stays false and is not replaced with the model default.
- `log_adjacency_changes` (Boolean) Log neighbor adjacency changes. A disabled value stays false and is not replaced with the model default.
- `originate_default` (Boolean) Originate a default route. A disabled value stays false and is not replaced with the model default.
- `originate_default_always` (Boolean) Always originate the default route. A disabled value stays false and is not replaced with the model default.
- `originate_default_metric` (Number) Metric for the originated default route, from 0 through 16777214. A blank or omitted value stays null. Literal 0 is a real value, not an unset sentinel.
- `router_id` (String) OSPF router ID as an IPv4 identifier without a mask. A blank or omitted value stays null and is not replaced with an empty string.
