# opnsense_quagga_rip (Data Source)

Reads the RIP settings singleton. The only accepted identity is `rip`. This data source calls the stable Quagga/FRR GET and never writes or reconfigures the service.

The public allowlist is the resource contract that the released RIP node returns: enabled, version, networks, redistribute, and default metric. `passiveinterfaces` is returned by the whole-model GET but is not resource refresh state, so it is not lookup state. The released RIP node has no password or write-only secret. Missing required fields are not replaced with model defaults. A disabled flag stays false. A blank optional metric stays null. Literal version or metric 0 fails closed.

## Example Usage

```terraform
# Read the RIP settings singleton.
# Identity is rip. The lookup never writes or reconfigures.
data "opnsense_quagga_rip" "example" {
  id = "rip"
}

output "rip_enabled" {
  value = data.opnsense_quagga_rip.example.enabled
}
```

## Schema

### Required

- `id` (String) Synthetic singleton ID. Must be `rip`.

### Read-Only

- `default_metric` (Number) Default metric for redistributed routes, from 1 through 16. A blank or omitted value stays null. Literal 0 is not the resource unset sentinel and fails closed.
- `enabled` (Boolean) Enable RIP. A disabled service stays false and is not replaced with the model default.
- `networks` (Set of String) IPv4 networks in CIDR notation that RIP advertises. An empty stored list stays an empty set. Selected-map key order is not stored order. A value that is not a dotted-quad prefix fails closed.
- `redistribute` (Set of String) Selected redistribution sources: `bgp`, `connected`, `kernel`, `ospf`, or `static`. An empty selection stays an empty set. An unknown selected token fails closed.
- `version` (Number) RIP version, 1 or 2. A missing or blank value fails closed and is not replaced with the model default of 2. Literal 0 fails closed.
