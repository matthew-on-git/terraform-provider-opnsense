# opnsense_quagga_static (Data Source)

Reads the FRR static routing settings singleton. The only accepted identity is `static`. This data source calls the stable Quagga/FRR GET and never writes or reconfigures the service.

The public allowlist is the resource contract that the released staticd node returns: enabled. The routes child array is returned by the whole-model GET but is not resource refresh state, so it is not lookup state. Manage individual routes with `opnsense_quagga_static_route`. The released staticd node has no password or write-only secret. A missing or blank enabled flag fails closed and is not replaced with the model default. A disabled flag stays false.

## Example Usage

```terraform
# Read the FRR static routing settings singleton.
# Identity is static. The lookup never writes or reconfigures.
data "opnsense_quagga_static" "example" {
  id = "static"
}

output "quagga_static_enabled" {
  value = data.opnsense_quagga_static.example.enabled
}
```
