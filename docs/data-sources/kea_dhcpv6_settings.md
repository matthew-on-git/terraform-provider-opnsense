# opnsense_kea_dhcpv6_settings (Data Source)

Reads the Kea DHCPv6 general settings singleton. The only accepted identity is `kea-dhcpv6`. This data source calls the stable DHCPv6 GET and never writes or reconfigures the service.

The public allowlist is the resource contract that the released general model returns: enabled, manual configuration, interfaces, valid lifetime, and firewall rules. Socket retry, decline probation, MAC sources, lease expiry, and HA nodes are not lookup state. DHCP socket type is absent from the stable general model, so it is not lookup state and is not replaced with a default. The released general model has no password or write-only secret. Missing required fields are not replaced with model defaults. A blank optional manual configuration stays null.

## Example Usage

```terraform
# Read the Kea DHCPv6 general settings singleton.
# Identity is kea-dhcpv6. The lookup never writes or reconfigures.
data "opnsense_kea_dhcpv6_settings" "example" {
  id = "kea-dhcpv6"
}

output "kea_dhcpv6_valid_lifetime" {
  value = data.opnsense_kea_dhcpv6_settings.example.valid_lifetime
}
```

### Required
