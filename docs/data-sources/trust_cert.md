# opnsense_trust_cert (Data Source)

Read public certificate/CSR metadata and API-returned sensitive material by UUID
without importing the object into Terraform management. This lookup performs no
writes and does not own generation, signing, reissue, activation or recovery.

Read-time action and generation template defaults are not original creation
provenance. A local-only one-time key is unavailable to lookup. Private material
returned by the API is Sensitive and stored in state; absent values are not
synthesized. Use appropriately restricted API credentials and protected state.

## Example Usage

```terraform
data "opnsense_trust_cert" "example" {
  id = "00000000-0000-4000-8000-000000000001"
}
```
