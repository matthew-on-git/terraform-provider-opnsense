# opnsense_kea_dhcpv4_settings (Data Source)

Reads the Kea DHCPv4 general settings singleton. The only accepted identity is `kea-dhcpv4`. This data source calls the stable DHCPv4 GET and never writes or reconfigures the service.

The public allowlist matches the resource contract: enabled, manual configuration, interfaces, valid lifetime, firewall rules, and DHCP socket type. Socket retry, decline probation, compatibility, lease expiry, and HA nodes are not lookup state. The released general model has no password or write-only secret. Missing required fields are not replaced with model defaults. A blank optional manual configuration stays null.

## Example Usage

```terraform
# Read the Kea DHCPv4 general settings singleton.
# Identity is kea-dhcpv4. The lookup never writes or reconfigures.
data "opnsense_kea_dhcpv4_settings" "example" {
  id = "kea-dhcpv4"
}

output "kea_dhcpv4_valid_lifetime" {
  value = data.opnsense_kea_dhcpv4_settings.example.valid_lifetime
}
```

## Schema

### Required

- `id` (String) Synthetic singleton ID. Must be `kea-dhcpv4`.

### Read-Only

- `dhcp_socket_type` (String) DHCP socket type: raw or udp.
- `enabled` (Boolean) Enable the Kea DHCPv4 server.
- `firewall_rules` (Boolean) Automatically add firewall rules for the service.
- `interfaces` (Set of String) Interfaces the DHCPv4 server listens on.
- `manual_config` (Boolean) Manage the Kea config file manually (disable GUI management). A blank optional value stays null.
- `valid_lifetime` (Number) Default lease valid lifetime in seconds.
