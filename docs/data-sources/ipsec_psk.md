# opnsense_ipsec_psk (Data Source)

Look up an existing IPsec pre-shared key by UUID. The lookup publishes local identity, remote identity, key type, and description. The pre-shared key value is not lookup state, including when the appliance omits or returns the secret.

## Example Usage

```terraform
# Look up public metadata for an existing IPsec pre-shared key by UUID.
# The pre-shared key value is not lookup state.
data "opnsense_ipsec_psk" "example" {
  id = "12345678-1234-1234-1234-123456789012"
}

output "ipsec_psk_identity" {
  value = data.opnsense_ipsec_psk.example.identity
}
```
