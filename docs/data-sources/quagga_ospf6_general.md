# opnsense_quagga_ospf6_general (Data Source)

Reads the OSPFv3 general settings singleton. The only accepted identity is `ospf6`. This data source calls the stable Quagga/FRR GET and never writes or reconfigures the service.

The public allowlist is the resource contract that the released OSPFv3 node returns: enabled, router ID, default-route origination, origination metric, and CARP demote. Child arrays are not lookup state. The released OSPFv3 node has no password or write-only secret. Missing required fields are not replaced with model defaults. A disabled flag stays false. A blank optional router ID or metric stays null. Literal metric 0 is a real value.

## Example Usage

```terraform
# Read the OSPFv3 general settings singleton.
# Identity is ospf6. The lookup never writes or reconfigures.
data "opnsense_quagga_ospf6_general" "example" {
  id = "ospf6"
}

output "ospfv3_enabled" {
  value = data.opnsense_quagga_ospf6_general.example.enabled
}
```

## Schema

### Required

- `id` (String) Synthetic singleton ID. Must be `ospf6`.

### Read-Only

- `carp_demote` (Boolean) Demote CARP if OSPFv3 is not converged. A disabled value stays false and is not replaced with the model default.
- `enabled` (Boolean) Enable OSPFv3. A disabled service stays false and is not replaced with the model default.
- `originate_default` (Boolean) Originate a default route. A disabled value stays false and is not replaced with the model default.
- `originate_default_always` (Boolean) Always originate the default route. A disabled value stays false and is not replaced with the model default.
- `originate_default_metric` (Number) Metric for the originated default route, from 0 through 16777214. A blank or omitted value stays null. Literal 0 is a real value, not an unset sentinel.
- `router_id` (String) OSPFv3 router ID as an IPv4 identifier without a mask. A blank or omitted value stays null and is not replaced with an empty string.
