# opnsense_kea_ctrl_agent (Data Source)

Reads the Kea DHCP control agent settings singleton. The only accepted identity is `kea-ctrl-agent`. This data source calls the stable control-agent GET and never writes or reconfigures the service.

The public allowlist matches the resource contract: enabled, listen address, and listen port. The released general model has no password or write-only secret. Missing required fields are not replaced with model defaults.

## Example Usage

```terraform
# Read the Kea DHCP control agent singleton.
# Identity is kea-ctrl-agent. The lookup never writes or reconfigures.
data "opnsense_kea_ctrl_agent" "example" {
  id = "kea-ctrl-agent"
}

output "kea_ctrl_agent_http_port" {
  value = data.opnsense_kea_ctrl_agent.example.http_port
}
```
