# opnsense_unbound_general (Data Source)

Reads Unbound general settings. The only accepted identity is `unbound-general`. This data source never writes, deletes, or reconfigures the service.

Released core 26.7.9 and 26.7.10 return the whole Unbound model from the settings GET. The public allowlist is the resource refresh contract. `safesearch` belongs to the DNSBL lookup. `belownxdomain` and sibling host, alias, forward, ACL, and blocklist nodes are not lookup state. The nodes have no password or write-only secret. A missing or blank required field fails closed and is not replaced with its model default. Optional booleans and integers stay null when blank. An empty optional string stays empty.

## Example Usage

```terraform
# Read Unbound general settings.
# Identity is unbound-general. The lookup never writes or reconfigures.
data "opnsense_unbound_general" "example" {
  id = "unbound-general"
}

output "unbound_general_enabled" {
  value = data.opnsense_unbound_general.example.enabled
}
```
