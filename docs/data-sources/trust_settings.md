# opnsense_trust_settings (Data Source)

Uses the released OPNsense 26.7.8 Trust general settings API. This read-only lookup
returns five stored Boolean policies and selected `CipherString` choice keys only.
It does not manage `Ciphersuites`, `SignatureAlgorithms`, `groups`, `MinProtocol`
or `MinProtocol_DTLS`, CA/certificate actions or full Trust lifecycle parity.

## Example Usage

```terraform
data "opnsense_trust_settings" "current" {}
```

## Schema

### Read-Only

- `cipher_string` (Set of String) Stored selected OpenSSL CipherString choice keys; an empty set means no selected choices.
- `enable_config_constraints` (Boolean) Enable custom OpenSSL configuration constraints. Stored policy only.
- `enable_legacy_sect` (Boolean) Enable OpenSSL legacy providers. Stored policy only.
- `fetch_crls` (Boolean) Schedule hourly CRL downloads using distribution points from CAs in the trust store. Stored policy only.
- `id` (String) Fixed singleton identity trust_settings.
- `install_crls` (Boolean) Store all configured certificate revocation lists in the default trust store. Stored policy only.
- `store_intermediate_certs` (Boolean) Allow locally defined intermediate certificate authorities in the local trust store. Stored policy only.

This lookup only reads authoritative values; it never saves or activates.
