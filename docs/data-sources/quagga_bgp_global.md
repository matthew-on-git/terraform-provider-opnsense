# opnsense_quagga_bgp_global (Data Source)

Reads the BGP global settings singleton. The only accepted identity is `bgp`. This data source calls the stable Quagga/FRR GET and never writes or reconfigures the service.

The public allowlist is the resource contract that the released general node returns: enabled, AS number, router ID, distance, graceful restart, network import check, enforce first AS, log neighbor changes, networks, and maximum paths. Bestpath and child arrays are not lookup state. The released general node has no password or write-only secret. Missing required fields are not replaced with model defaults. A present blank router ID, distance, or maximum-paths value stays null. A disabled service stays false.

## Example Usage

```terraform
# Read the BGP global settings singleton.
# Identity is bgp. The lookup never writes or reconfigures.
data "opnsense_quagga_bgp_global" "example" {
  id = "bgp"
}

output "bgp_as_number" {
  value = data.opnsense_quagga_bgp_global.example.as_number
}
```

## Schema

### Required

- `id` (String) Synthetic singleton ID. Must be `bgp`.

### Read-Only

- `as_number` (Number) Local autonomous system number. A missing value is not replaced with the model default.
- `distance` (Number) Administrative distance. A present blank value stays null and is not stored as zero.
- `enabled` (Boolean) Enable BGP. A disabled service stays false.
- `enforce_first_as` (Boolean) Enforce the first AS in the AS-path of eBGP updates.
- `graceful_restart` (Boolean) Enable graceful restart. A disabled value stays false.
- `log_neighbor_changes` (Boolean) Log neighbor up and down changes.
- `maximum_paths` (Number) Maximum eBGP ECMP paths. A present blank value stays null and is not stored as zero.
- `maximum_paths_ibgp` (Number) Maximum iBGP ECMP paths. A present blank value stays null and is not stored as zero.
- `network_import_check` (Boolean) Check BGP network route existence in the IGP before announcement.
- `networks` (Set of String) Networks in CIDR notation advertised into BGP. An empty list stays empty.
- `router_id` (String) BGP router ID. A present blank value stays null.
