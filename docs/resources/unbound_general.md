# opnsense_unbound_general (Resource)

This singleton retains the established `opnsense_unbound_general` name and fixed import ID. It owns only the general, advanced, ACL-default, and forwarding-enable branches. `terraform destroy` removes it from state without resetting appliance settings.

The legacy `no_aaaa_records` attribute maps to OPNsense's `noarecords` control, which removes A records despite the historical Terraform name. Each successful mutation is activated once through the Unbound general reconfigure endpoint.

On stable OPNsense releases older than 26.7.7, the established general-branch attributes continue to use the legacy wire contract and reconfigure endpoint. The advanced, ACL-default, and forwarding-enable parity attributes require stable OPNsense 26.7.7 or newer; configuring one on an older or unverifiable appliance returns an explicit compatibility error.

## Example Usage

```terraform
resource "opnsense_unbound_general" "resolver" {
  enabled            = true
  port               = "53"
  hide_identity      = true
  hide_version       = true
  enable_prefetch    = true
  aggressive_nsec    = true
  acl_default_action = "allow"
  forwarding_enabled = true
}
```

## Import

```shell
terraform import opnsense_unbound_general.resolver unbound-general
```

Unset advanced integer settings are read as null and omitted from updates, preserving appliance defaults. Explicit zero remains a configured value.
Empty cache-size and serve-expired tuning strings also retain their appliance-default representation.
