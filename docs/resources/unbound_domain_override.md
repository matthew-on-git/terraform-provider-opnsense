# opnsense_unbound_domain_override (Resource)
Manages an Unbound DNS query or DNS-over-TLS forward on OPNsense. `type = "query"` routes mutations through the forward endpoints and defaults an omitted `server_port` to 53; `type = "dot"` routes through the DoT endpoints and defaults an omitted port to 853. An explicitly configured port is always preserved. A blank `verify_cn` is valid for intentionally unverified or self-signed TLS.

The established query-forward shape remains supported on older stable OPNsense releases through its legacy response and reconfigure contract. DNS-over-TLS, a non-53 query port, or a non-empty `verify_cn` requires stable OPNsense 26.7.7 or newer. Current releases are decoded strictly; missing type or port fields are not silently defaulted.
## Example Usage
```terraform
resource "opnsense_unbound_domain_override" "corp" {
  domain      = "corp.example.com"
  type        = "query"
  server      = "10.0.0.53"
  server_port = 53
}

resource "opnsense_unbound_domain_override" "private_dot" {
  domain      = "private.example.com"
  type        = "dot"
  server      = "192.0.2.53"
  server_port = 853

  # Blank is valid and deliberately disables certificate-name verification.
  # Set this to the upstream certificate name whenever possible.
  verify_cn = "dns.example.com"
}
```

## Schema

### Required

- `domain` (String) Domain to override (e.g., `example.com`). Use an empty string for global forwarding.
- `server` (String) IP address of the DNS server to forward queries to.

### Optional

- `description` (String) Description of the domain override.
- `enabled` (Boolean) Whether this domain override is enabled. Defaults to `true`.
- `server_port` (Number) Destination server port. When omitted, query forwarding defaults to 53 and DoT defaults to 853; an explicit value is preserved.
- `type` (String) Forward type: `query` for ordinary DNS or `dot` for DNS over TLS.
- `verify_cn` (String) TLS certificate name for DoT. A blank value intentionally permits an unverified or self-signed server.

### Read-Only

- `id` (String) UUID of the domain override in OPNsense.
## Import
```shell
terraform import opnsense_unbound_domain_override.example 12345678-1234-1234-1234-123456789012
```

Set `domain = ""` for a global forwarder. The empty domain is preserved for both ordinary DNS and DNS over TLS.
